## Zweck

Diese Datei zerlegt SPERRFRIST horizontal in zwölf dramaturgische Makro-Bausteine. Sie erhöht bewusst die Abhängigkeitskomplexität gegenüber M1, ohne bereits Beats, Szenen oder Prosa festzulegen.

## Horizontaler Gesamtcheck

- **12 Bausteine** erfüllen den M2-Korridor von mindestens 10.
- B01–B03 setzen Ausgangsmaterial, Informationsarchitektur und Zeitdruck.
- B04–B06 zerlegen die anfängliche scheinbare Einheit von T und K über reale Gegeninformation.
- B07 erzeugt einen echten Quellenschutz-/Beziehungsfolgeschaden aus einer legitimen Recherchehandlung.
- B08–B10 definieren publizierbare Grenzen, erhöhen T-Relevanz und testen Loyalität zur Quelle.
- B11 ist ein **geplanter Story-Reversal**, kein Framework-Invalidierungstest: technische Kernkritik stärker, konkrete Wissenszuschreibung falsch.
- B12 schließt nicht mit Täter-Twist, sondern mit engerer Behauptung und realem Wettbewerbs-/Beziehungspreis.
- Kein Baustein benötigt einen Hacker, Geheimdienst, allwissenden Informanten oder künstlich bösen Chefredakteur.

## Cross-Block-Abhängigkeiten

1. **T-Strang:** B01 → B02 → B04 → B05 → B06 → B09 → B11 → B12.
2. **K-Strang:** B01 → B02 → B05 → B06 → B08 → B10 → B11 → B12.
3. **Nora–David:** B03 Konflikt → B08 pragmatische Annäherung → B09 gemeinsame Priorität → B12 Restkonflikt über Timing.
4. **Nora–Jonas:** B02 Vertrauen → B07 Schutzfehler → B11 fachliche Rehabilitation.
5. **Nora–Quelle A:** B01 Schutz-/Vertrauensbasis → B06 erste Distanz → B07 Schutzkrise → B10 Deutungskonflikt → B12 Schutz bleibt trotz inhaltlicher Abgrenzung bestehen.

## Framework-Backtracking-Abgrenzung

B11 darf später **nicht** als M2-Invalidierungsnachweis gezählt werden, weil der Reversal bereits auf G1-Ebene kanonisch bekannt ist. Der echte Invalidierungstest erfolgt separat erst nach Existenz realer Downstream-Artefakte durch eine dokumentierte relevante Upstream-Teständerung.
